LATEST SWEEPER / GRABBER

One fixed three-slot sweep, two grabber modes

Latest and Latest + Native Smoothing use the same sweeper and the same three physical slots. Latest grabs the currently completed slot immediately. Native Smoothing grabs the complete N-2 / N-1 / N window. Neither mode adds Ring-3 work to the packet hot path.
