This is a synthetic monitoring workload for research/demo purposes. It is not a safety-control, protection-relay, or production energy-system claim.

Latest per tag

If an older measurement becomes obsolete before it is useful, the newest state is what matters to the monitoring view.

Browser stays lightweight

The HMI is a sampled representation. It polls compact telemetry about once per second and never receives the high-rate tag stream.

Control remains separate

This demo is telemetry/state replication only. Critical switching, trips, interlocks, and protection actions require stronger operational guarantees.
