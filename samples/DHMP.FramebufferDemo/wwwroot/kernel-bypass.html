This is a directional TX-path comparison, not an end-to-end latency test. Raw IPv6 measures synchronous submission through the normal Linux raw-socket/kernel path onto the benchmark veth. AF_XDP measures TX completion through its UMEM/ring fast path on the same veth. Both use the same payload and packet count. No production network traffic is generated.

Same workload

Both paths transmit the same number of packets with the same useful DHMP payload and fixed 16-byte record accounting.

Same host and interface

Both benchmarks execute inside the same deployed container against the same isolated benchmark veth, avoiding differences between machines.

Alternating order

Raw IPv6 runs first on one sample pair and AF_XDP first on the next, reducing systematic warm-up and first-run bias.
