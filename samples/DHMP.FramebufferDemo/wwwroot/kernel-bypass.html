This is a live AF_XDP TX-path benchmark on an isolated veth pair inside the demo container. It measures AF_XDP descriptor completion and useful DHMP payload rate. It is not an end-to-end Internet result and does not claim remote delivery latency. The displayed mode is the mode actually initialized by the host.

Zero-copy first

The backend requests AF_XDP zero-copy on every run. If the veth/driver cannot expose it, the native backend falls back to AF_XDP copy mode and reports that explicitly.

No production traffic

The benchmark uses a private veth pair inside the container rather than sending synthetic benchmark frames onto the server's external network interface.

Compare with the normal lab

The normal Throughput Lab measures DHMP API/framing processing. This page measures the experimental network fast-path boundary, so the numbers answer a different question.
